# Supplied security-report triage — 2026-10-03

Status: static source-impact triage of three supplied v0.4.96 reports against
commit `f7b4b993`. This is not a dynamic pentest, hosted-service assessment, or
physical-device certification.

The product owner required explicit approval before any functional change
proposed by these reports. Accordingly, this pass changes release governance,
licensing, and truthful documentation only. No report-proposed wallet, UI,
credential, export, filesystem, gateway, label, or transaction behavior was
implemented.

Verdicts use `confirmed`, `not_actionable`, and `needs_review`. “Confirmed” does
not mean approved for implementation; the approval column remains controlling.

## Implementation boundary

The only implemented security-related change from this triage is the release
authorization guard for the independently confirmed governance failure. No
functional recommendation from any report was implemented. If the owner
approves one or more candidates later, each should receive a separate minimal
patch, threat-model update, regression evidence, and explicit compatibility/BIP
assessment.
