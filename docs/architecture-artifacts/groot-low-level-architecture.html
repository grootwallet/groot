Secret lifecycle

1 · UI field

Credential exists transiently in mounted route; clears after use. Mnemonic is absent from production webview.

→
2 · Tauri command

Bounded string crosses IPC for credential only; no payload logging.

→
3 · Rust

Zeroizing buffers authenticate envelope, derive seed/descriptors, or authorize action.

→
4 · Cleanup

Credential/seed buffers zeroize; bounded public descriptor binding may remain in unlocked session.

Mnemonic · seed · xpriv · private descriptor · decrypted signing material → NEVER to webview, analytics, logs, clipboard, or notifications.

Attack surfaces & stated controls

Webview / IPC

Public DTO allowlist, stable errors, deny-by-default CSP, boundary scripts. Credential necessarily crosses IPC; mnemonic does not.

HWI process

Absolute reviewed path, public-network Unix provenance checks, cleared environment, exact args/path/fingerprint, bounded output and time. Vendor/device UI remains external trust.

Filesystem

Owner-only files, symlink/type checks, process lock, UUID isolation, atomic rename/transactions. No secure-erasure claim.

Core / Tor

Exact route + credentials binding, chain check, HTTPS/no redirects, explicit numeric loopback SOCKS, bounded framing. Endpoint availability/privacy is user/external trust.

Compact filters

Peer diversity/manual numeric restrictions and atomic apply. Confirmed-only; adversarial peer and durable cache work remain gated.

Unresolved / partial

  • Desktop Rust/Tauri Regtest is the functional center; mobile native secret surfaces and platform certification remain incomplete.
  • Non-Apple secure-store provider intentionally fails closed on public networks; Android/Linux/Windows production storage is not claimed.
  • Generic single-key send retains persisted proposal state but offers no UI selector after restart.
  • Compact-filter headers/filters are memory-only in the pinned engine; recovery and P2P broadcast remain gated.
  • Payjoin V2 stops at bounded URI parsing; transport/session/re-review/fallback work is absent.
  • Guided delayed-path satisfaction and decaying/expanding policies are preview/gated.
  • Package signing, notarization, update inputs, reproducibility and lifecycle acceptance are not complete release evidence.
  • Mainnet is compile-time disabled; dormant code is not enabled-path proof.
