# 5.3 iPhone layout correction

The owner reported the welcome header overlapping iPhone time/battery and a pinch-zoomed viewport. The full-screen setup overlay now reserves the platform's top and landscape side safe areas. Its header cannot shrink when a form needs scrolling. Mobile welcome home retains the card mark, hides the duplicate header lockup, and keeps network/settings visible with 44-point controls.

After native runtime identification, mobile alone constrains the viewport to scale 1 and cancels WebKit pinch gestures. Single-finger scrolling, browser zoom and desktop keyboard zoom are preserved. Startup network/version checks and ADR 0089's mobile operation restrictions remain intact.

Compatibility: no wallet/profile/backup/proposal/registry format changes or migrations. **No BIP impact**: presentation and viewport behavior only; no wallet, signer, transaction or protocol changes. No source-policy pin refresh or public release authorization.
