# 5.3.0 draft PR 119 release gates

Draft PR [#119](https://github.com/grootwallet/groot/pull/119) combines the 5.3
candidate work without merging to main. On 2026-10-22 the owner attested that
independent review of the Mainnet HWI change was complete and authorized an
unsigned internal speed candidate. The PR's visible `ack` is the owner's
attestation; it is not a GitHub review submission. GA still requires a recorded
independent review of the exact release source and artifact.

The internal multi-network candidate routes Mainnet HWI operations through the
sealed runtime only when the compile-time protocol is `1`. Native and worker
validation bind the active chain, explicit `main` HWI selector, Mainnet BIP84 or
BIP48 account path, `xpub` identity, selected device, and one requested action.
Testnet4 uses its separate scope; Jade's shared `test` selector cannot enter
Mainnet. Fixed Mainnet builds lack the extracted runtime and retain the legacy
HWI path. No wallet, registry, backup, proposal, or credential format changes.

Before building the internal candidate, review and update the Mainnet source
policy against this exact source, including the operation-session worker and
runtime files. `pnpm validate`, strict Rust checks, hardware preflight, and the
exact package's original HWI digest, extracted-runtime manifest, app seal,
bundle identity and build metadata must pass. Local unit and fixture results
do not certify physical Mainnet signers.

The owner will test all seven exact devices on the same unsigned Mainnet RC:
discovery, identification, health, address display, transaction review,
signature return, cancellation, locked/disconnected recovery, and restart.
Record firmware and first/warm timings. Mainnet GA remains gated on those
physical results, an independent exact-source review, and the normal signed
release checklist; this draft is not merged or public.
