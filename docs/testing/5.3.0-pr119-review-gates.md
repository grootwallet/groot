# 5.3.0 draft PR 119 release gates

Draft PR [#119](https://github.com/grootwallet/groot/pull/119) combines the
5.3 candidate work without merging to main. The owner reported reviewing the
draft on 2026-10-22. That review covers the published source at the time;
the PR still limits the faster HWI session to Testnet4 and contains no
Mainnet speed activation to review or physically test.

The initial PR checks failed for two distinct reasons: the retained Mainnet
source-policy snapshot rejects the changed `src-tauri/src/session.rs`, and
Linux strict Clippy found an unused `active_chain` argument in the HWI runner.
The latter is a compile-only conditional-use correction; it does not alter
the HWI command, network, wallet format, BIP support, USB operation, signature
verification or profile data. The source-policy pin remains untouched pending
review of the complete 5.3 Mainnet-critical diff.

An exact fast Mainnet RC requires reviewed Mainnet selector/path/xpub handling
in the sealed HWI worker and native gates, passing source-policy and Rust/CI
checks, verified packaging, then owner-observed speed and negative-state tests
for all seven exact devices. A Testnet4 result or an RC with the old Mainnet
path is not that evidence. No merge, new Mainnet speed RC or GA release is
authorized by this record.
