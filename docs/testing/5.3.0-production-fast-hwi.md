Historical pre-publication source-gate record. The desktop [v5.3.0 release](https://github.com/grootwallet/groot/releases/tag/v5.3.0) was published 2026-10-23 at `6a39bf50b2a6a042354b43369765a9af2174d061`. The owner authorized the Developer ID-signed Mainnet fast runtime on

the future signed package.

## Source and release-input checks

- The build script admits a runtime only for the multi-network macOS build;
  Developer ID team `6Z85HGDUU7` additionally requires exact version 5.3.0,
  a frozen source HWI digest, and session protocol 1. Fixed-network builds,
  other teams and other versions fail closed.
- The extracted runtime is derived from the separately verified, pinned and
  signed HWI 3.2.0 input. Every extracted Mach-O is Developer ID-signed with
  hardened runtime and a timestamp before its manifest is frozen. The
  framework, signer team, file inventory, symlinks and source digest are
  verified without opening a hardware device.
- Two initially clean, isolated unsigned executable builds compile the same
  frozen runtime manifest SHA-256. ADR 0105 allows them on one Mac for v5.3.0
  only. The macOS packager checks that evidence and copies the
  exact runtime before signing the outer app; it re-verifies the runtime after
  copying, signing and notarization.
- The existing native one-operation worker still binds the active chain,
  account path, full live fingerprint/xpub, selected device and allowed action.
  The native layer verifies displayed transaction data and returned signatures.
  No live state survives the worker process.
