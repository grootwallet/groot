## Compatibility and release

No wallet, profile, registry, encrypted envelope, proposal, backup or label format changed. Existing data stays readable; no migration/discard or receipt store was added. No dependency, published tag/artifact, update key or reviewed-source hash changed. The new IPC outcome and bundled renderer change together. SegWit PSBT transaction identity and existing BIP125/174 behavior are preserved; tests extend application-level failure/recovery evidence, not standards/platform certification.

The mobile key/signing/broadcast rejection remains intact. Baseline version numbering remains unchanged; these modifications are not a 5.3 release authorization. The 5.2 source-review gate is deliberately preserved and must be resolved through the proper reviewed candidate process before distribution.
