These are named regression obligations; their presence is not a new claim of physical or native certification.

No native command, WalletPort contract, secret handling, descriptor, transaction review, signer authority, stored wallet format, dependency, platform capability or release authorization changes in this five-file diff. Frontend capability checks do not replace Rust authorization.
